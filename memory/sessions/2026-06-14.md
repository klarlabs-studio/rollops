## Decisions Made
- **Plugin marketplace = curated Git-reviewed JSON index** (`registry/plugins.json`),
  no service. sha256 pin is the trust anchor; install enforces it + auto-cosign-verifies
  when the index declares a signer. Chosen over a hosted registry: zero infra, reviewable in PRs.
- **Gap-close vs ArgoCD via plugin capabilities, not core bloat.** Added `trafficrouter`
  + `metricprovider` capabilities (mirror flag-provider pattern) so traffic routing +
  pluggable metrics extend the marketplace moat instead of fattening the core. Deliberately
  did NOT build ApplicationSet generators / Jsonnet / app-of-apps / heavy resource-tree UI.
- **The load-bearing fix: real canary traffic.** Engine was apply-once + health-bake; weight
  only drove the feature flag. Now drives a trafficrouter plugin's SetWeight per step. This was
  the one thing undercutting the "progressive delivery" claim.
- **Image automation modes: semver (minor/major/patch) + digest.** Registry reality forced it —
  4 of the klarlabs marketing sites tag `:latest`+commit-SHA (no semver) → digest mode (pin
  `:latest`'s manifest digest, keel "force" parity); semver only fits genuinely-versioned apps.
- **Config-in-app-repo, not a central config repo** (operator's call). Each app's `.rollops/`
  lives beside its code; image-automation bumps push back there. Matches one of ArgoCD's two
  standard layouts. Caveat surfaced + accepted: works because their CI builds on release, not on
  every push (no CI loop).
- **Multi-org git auth = classic PAT** (`repo` + `read:packages`). Fine-grained PATs are
  single-owner + selected-repos → can't span klarlabs-studio + felixgeelhaar. Roady #34 tracks
  the least-privilege successor (per-repo deploy keys / GitHub App).
- **v0.16.0 cut + cluster moved to the official tagged image** (off throwaway `fleet3`).

## What Went Wrong
- **~8 real bugs only surfaced on live infra** (the whole point of dogfooding):
  - `Watcher.Run` discarded Tick outcomes → reconcile loop totally silent; hid every error.
  - Image automation error `continue`d → blocked the whole app's reconcile (should be best-effort).
  - One unreachable repo made `NewWatcher` abort → rollopsd CrashLoop (now logs+skips).
  - **git token leaked into pod logs** (http.extraheader in the logged git command on a clone crash) → added `redactArgs`.
  - Shallow stamped-drift missed `kubectl set image`; `Apply` also wouldn't self-heal it (short-circuited on matching stamp) → added `verification: full` + Apply diff-before-skip.
  - `LoadFromDir` reads ONE file; watch path pointing at a dir 403'd silently until the logging fix.
- **SECURITY: operator pasted tokens into the FleetView session 3×** (1 fine-grained, 2 classic) → each landed in the transcript → each compromised + must be revoked. Repeatedly told them: create the k8s secret in their OWN terminal with `read -rs`, never paste to the agent. The git-auth diagnosis took several round-trips (fine-grained vs classic, then public-only scope, then a stale secret that wasn't actually recreated).
- ghcr fine-grained PAT can't read org container packages → metric/image scan 403; needs classic + `read:packages`.
